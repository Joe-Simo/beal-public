## 1. Executive result

The U105 modular pathway cannot currently be used as a proof. Three independent defects were found:

1. **Object conflation:** U105 combines arithmetic belonging to two different curves/Jacobians.
2. **Internal group-theoretic contradiction:** it asserts both projective image (V_4) and projective inertia of order (5).
3. **False residual-modularity citation:** Allen--Khare--Thorne (2021), Theorem 1.2, is quoted as an arbitrary-(p) residual modularity theorem, but its actual theorem only treats specific small residue fields.

The third defect is **repairable at the modularity stage** because Azon's Theorem 5.4 supplies modularity for the relevant negative Frey compatible system. The remaining difficult point is a correctly justified level-lowering bridge for this specialization.

## 2. Object conflation

### 2.1 The solution-dependent genus-2 Frey curve

For a putative solution, U101 uses
[
U=X^2,qquad V=2Y^2,qquad U^5+8V^5=Z^{17},
]
and the quintic Frey model
[
C^-_{U,V}:quad y^2=-f_{U,V}(x),
]
where
[
f_{U,V}(x)=x^5+40UVx^3+320U^2V^2x+64(8V^5-U^5).
]

This is a **genus-2** curve. Its Jacobian is an abelian surface with RM by
[
K=mathbb Q(sqrt5).
]
Because (17) is inert in (K), the residual RM component naturally has coefficient field
[
mathcal O_K/(17)congmathbb F_{17^2}=mathbb F_{289},
]
so this path studies
[
arho_{U,V,17}:G_K	omathrm{GL}_2(mathbb F_{289}).

### 2.2 The fixed genus-8 curve

U100--U103 also study the fixed auxiliary curve
[
C^-_{mathrm{aux}}:quad v^2=phi+2-4(3-phi)u^{17},
]
of genus (8). Its Jacobian has a cyclotomic endomorphism structure over an algebraic closure, and U103 constructs a different claimed two-dimensional residual component over (mathbb F_{17}).

These are not the same Jacobian, not the same dimension, not the same coefficient field, and not the same dependence on a hypothetical Diophantine solution.

### 2.3 U105 mixes them

U105 describes (C^-(U,V):y^2=-f(x)) as “genus-8,” then gives the (mathrm{GL}_2(mathbb F_{289})) target from the genus-2 RM surface, while importing U103's projective-image statement from the fixed genus-8 auxiliary curve.

This invalidates the dependency chain as written. Any repaired proof must choose one Frey object and verify every modularity, conductor, local-type, image, and level-lowering statement for that same object.

## 3. Exact projective-image contradiction

For the genus-2 Frey representation, the local calculation at the prime (mathfrak p_2mid2) gives tame inertia generated by an element whose two eigenvalues on an RM component are
[
zeta_5,qquad zeta_5^{-1}.
]

In projective linear coordinates, the scalar-invariant eigenvalue ratio is
[
zeta_5^2,
]
which has exact order (5). Therefore the projective image contains an element of order (5).

But U105 also asserts
[
mathbb Poperatorname{im}(arho)cong V_4,
]
or a subgroup of (V_4). The Klein four-group has order (4), hence no element of order (5).

Thus those two assertions cannot describe the same residual representation.

This is not a subtle literature issue; it is an exact finite-group contradiction.

## 4. Allen--Khare--Thorne is misquoted

U101 states:

> Allen--Khare--Thorne (2021, Theorem 1.2) proves that any continuous, totally odd, absolutely irreducible (arho:G_K	omathrm{GL}_2(overline{mathbb F}_p)) whose restriction to (G_{K(zeta_p)}) is irreducible is modular.

That is not the theorem in the cited paper.

The actual paper is:

Patrick B. Allen, Chandrashekhar B. Khare, Jack A. Thorne,  
*Modularity of (mathrm{PGL}_2(mathbb F_p))-representations over totally real fields*,  
PNAS 118 (2021), e2108064118.

Its Theorem 1.2 concerns projective Serre-type representations and gives automorphy under a finite list of small residue-field cases:
[
|k|in{2,3,4},
]
certain (|k|=5) cases, (|k|=7) with a parity condition, and (|k|=9) with a parity condition.

It is not a blanket residual modularity theorem for a mod-(17) representation over (mathbb Q(sqrt5)).

This same project already contains an older checkpoint that correctly records the theorem as a mod-5/small-residue-field result, confirming that the U101 paraphrase is a regression.

## 5. Modularity itself has a different valid source

The false AKT citation does not by itself kill the modular strategy.

Martin Azon, *Effective Darmon's program for the generalised Fermat equation*, arXiv:2504.01967v2, Theorem 5.4, proves modularity of the compatible system attached to the negative Frey Jacobian (J_r^-). Its proof extends the residual representation to (G_{mathbb Q}), applies Serre modularity, cyclic base change, and a modularity-lifting theorem.

Therefore, for the negative genus-2 Frey system used by this weighted equation, modularity can be sourced from Azon rather than from the inapplicable AKT theorem, provided the specialization matches Azon's construction as already checked upstream.

## 6. The actual remaining bottleneck is level lowering

Azon's paper separates modularity from level lowering.

Its packaged level-lowering theorem is proved in a section where **Hypothesis 5** is in force. That hypothesis requires a prime
[
q'
mid 2r
]
with
[

u_{q'}<0,qquad 
u_{q'}
otequiv0pmod r.
]

The project's U96 audit already found that this condition fails identically for the weighted specialization: the relevant negative valuations away from (2) and (5) are multiples of (5).

Azon's proof uses the resulting unipotent prime to obtain the cyclotomic-restriction irreducibility input and then invokes Breuil--Diamond.

The project subsequently attempted to reconstruct Breuil--Diamond Theorem 3.2.2 directly by supplying local characteristic-zero lifts at (2,5,17) and an independent cyclotomic-restriction argument. That is a legitimate research direction, but it must be audited on its own merits; it cannot inherit validity from Azon's packaged theorem once Hypothesis 5 fails.
